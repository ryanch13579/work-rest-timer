# Work Rest Timer

A lightweight fitness timer built with Flutter to track work and rest intervals during workouts. Designed to help users manage exercise and recovery periods, with the flexibility to adapt the timer for other use cases.

## Features

- **Work and Rest Intervals** — Track exercise and recovery periods during workouts.
- **Cross-Platform Framework** — Built with Flutter for potential deployment across multiple platforms.
- **Customisable Use Cases** — Adapt the timer for different workout routines or other timed activities.

## Tech Stack

- **Flutter** — Cross-platform application framework
- **Dart** — Primary programming language
- **Flutter TTS** — Text-to-speech package dependency

## Getting Started

### Prerequisites

Install the following before running the project:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart) (included with Flutter)
- An IDE such as [Visual Studio Code](https://code.visualstudio.com/) or Android Studio

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ryanch13579/work-rest-timer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd work-rest-timer
   ```

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
